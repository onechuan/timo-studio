# 架构图与 Workflow

本目录保存可直接在浏览器中打开的交互式图表。HTML 文件包含缩放、聚焦、路径查看和导出能力；`source/` 保存对应的 Archify JSON 候选文件，便于后续修改。

## 图表

1. [Director Harness 与多 Agent 协作架构](agent-harness.html)
   - 说明用户、Director Harness、Planner、Page Agent、Reviewer、视频引擎、配音工具与项目工作区之间的关系。
2. [整部影片 Workflow](whole-film-workflow.html)
   - 说明调研、分镜、人工确认、口播、配音、逐页生产、全片复核和 Ready 状态。
3. [单页检查与返工 Workflow](single-page-workflow.html)
   - 说明 Page Agent、确定性检查、Reviewer verdict、局部 edit 和有限轮重试。
