# Open-source source code

TimoTV and its programmable drawing engine are distributed under
AGPL-3.0-only. The initial drawing-engine baseline was derived from Frametell,
package `@frametell/engine` version `0.8.0`, by Sitor Team:
<https://github.com/sitor-ai/frametell>.

The engine source is vendored in `packages/drawing-engine` and is maintained in
this repository. Building, testing, and running TimoTV does not require a
Frametell checkout or any Frametell package.

Users receiving the application or interacting with a modified network version
must be offered the Corresponding Source required by AGPL-3.0-only. A build's
source must match that build; an older checkout is not sufficient.
