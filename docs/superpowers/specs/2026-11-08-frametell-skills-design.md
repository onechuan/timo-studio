# 参考帧言优化内置创作 Skills

用户授权在现有 TimoTV Skills 中借鉴帧言提示词。保留代码选择方向、阶段审批、submit JSON 和当前模板渲染能力。

## 设计

- 基础提示词保留角色、阶段、数据格式和内容安全边界；写作方法归入 Skills，避免多处冲突。
- `skills/shared/planning.md`、`skills/shared/script.md` 放三个方向共同适用的导演方法和口播打磨规则；加载器只加载当前阶段。
- 三个方向的独立参考保留其差异：通用讲解重视取舍和结构，科普重视因果与成立条件，产品介绍重视场景和事实依据。
- 分镜先确定受众和一句核心回答，按解释需要排序；画面意图具体，beats 适配当前模板的短标签，结尾回到开场问题。
- 口播按篇幅安排自然断句，区分 VO 与 Visual；明确需要逐字保留时不改原文。短材料不为凑时长增加空话。
- 写稿 user 消息补上原始 topic，避免主题中的用户要求在规划后丢失。

## 参考边界

阅读帧言 `packages/agent/prompts/PLANNER.md`、`PAGE.md`、`REVIEW.md`，提炼通用写作和检查方法，按 TimoTV 重新编写中文规则。不移植文件编辑、脚本执行、绘图 API、逐词时标、页面审核工具或样式组件要求。

当前 renderer 展示按页进度渐显的节点与短标签，visual 是分镜意图，不是绘图指令。优化文字不会使模板自动获得自由绘图或逐词同步能力。

## 验证

先记录旧规则的离线场景结果和缺口；回归测试先验证共享阶段规则及 topic 传递缺失，再实现加载与提示词调整。对短资料、原稿混排、稀疏产品事实做独立场景检查；运行导演测试、类型检查及使用注入模型的制作集成测试。不将离线检查表述为真实 DeepSeek 质量评测。
