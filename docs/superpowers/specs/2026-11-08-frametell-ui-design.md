# TimoTV Studio UI

用户要求参考帧言 UI 并直接在现有 TimoTV 实现。设计采用帧言的细边框及紧凑顶栏；按照用户后续要求，配色沿用 TimoTV 原来的深灰蓝背景与青柠绿强调色，保留 TimoTV 名称和播放标识。

首页使用居中创作输入区：主题为主，资料和详细设置可展开。保留无标题创建、文本导入、类型、画幅、时长、语言、风格和火山 TTS 设置，下方为最近项目。

生成类项目工作台采用左右分栏：左侧导演区展示主题、真实制作进度、分镜审批和重新规划意见；右侧画面工作台展示真实预览、可选择的分镜列表和分镜 / 口播 / 导出标签。未生成时使用明确的空状态，分镜卡片是结构化提纲而非伪造生成缩略图。手机使用导演 / 画面切换，所有操作可访问。

服务配置状态来自 API；不提供无法保存的配置输入。编辑项目原有重命名、时间轴、诊断保留。现有任务锁、轮询恢复、修订号、失败动作重试、视频画幅和下载均保留。验证包括浏览器测试、类型和构建，以及桌面和手机截图。仅本地实现，不发布或提交现有用户变更。
