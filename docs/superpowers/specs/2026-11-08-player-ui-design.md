# 视频预览播放器

参考帧言 `packages/engine/runtime/player.js` 的画面优先、底部浮层、暂停入口和键盘操作，使用 TimoTV 原有深色与青柠色重新实现。

- 暂停时中央播放入口；播放时闲置隐藏控制层，指针移动或键盘焦点唤回。
- 底部进度条、当前/总时长、播放暂停、静音、0.75–2 倍速、全屏；空格/K 播放暂停，左右键跳转 5 秒，M 静音，F 全屏。
- 原生 range/select 和有名称的按钮支持键盘操作；表单控件内的键盘输入不被播放器快捷键截获。
- 横竖屏和全屏保持画幅；窄屏控制条缩紧，音频加载或播放失败显示可操作的提示。

## 实现边界

`packages/renderer/src/preview.ts` 是无 Node 依赖的纯 HTML 模板；`player.ts` 生成独立控制层。API 从 renderer 的 `./preview` 子入口读取模板，不加载 Chrome、FFmpeg 或执行制作任务。

预览读取路由仍先核对产物归属、真实路径和文件存在，再用当前 Production 与新模板返回预览 HTML。旧项目刷新立即使用新播放器，不修改现有文件、不重新配音。音频仍走原有 Range 文件路由。

Worker 导出使用同一画面模板的 `controls: false` 模式，画面在固定画幅容器内呈现，只有显式 renderAt(t) 更新；不创建音频元素、控件或 RAF 循环，不把播放器录入 MP4。

## 验证

真实音频与 sandbox iframe 集成测试覆盖旧预览升级、播放暂停、拖动、静音、倍速、空格键、结尾重播、全屏及竖屏比例。制作集成测试继续验证真实 MP4 导出。工作台浏览器测试覆盖桌面/手机、16:9/9:16 的操作与布局，使用有 Range 响应的静音 WAV 测试文件；测试不调用外部生成服务。
