# 设置页与火山音色

用户要求模型 API、Key 在配置页填写，并提供火山 TTS 音色列表。沿用原有深灰蓝与青柠绿配色，新增顶栏入口和 #settings 独立页面，分为导演模型和配音服务。

模型保存 provider、model、baseUrl、protocol、API Key；配音保存火山 Key、默认音色、资源 ID，以及 ElevenLabs Key 和默认音色。私有配置文件 .data/config/settings.json 在服务端以 0600 权限原子写入，API 与 Worker 共用；页面仅接收 apiKeyConfigured 标志，不回传 Key。空输入保留，null 明确清除（覆盖 env 兜底）。版本号阻止并发覆盖。写入校验 JSON 和本机来源。

保存后新任务读取新配置；已执行任务保持启动快照，不写 process.env、不要求重启。.env 继续作为初始兜底。

火山音色采用官方预置目录，支持名称/ID 搜索、默认音色与项目音色选择、自定义 ID、短文本试听。明确标注这是官方预置目录，并非账号已开通列表。ListSpeakers 是控制面接口，不能把 TTS API Key 当作其鉴权。试听由服务端合成，测试使用 HTTP 替身，不发起付费请求。

配置缺失提示链接到设置页；保存失败保留输入；返回工作台重新获取 capabilities。验证构建、类型、状态恢复、密钥保留/清除/脱敏、运行时热更新和桌面/手机交互。保留全部已有制作功能及未提交改动，不公开部署或提交。
