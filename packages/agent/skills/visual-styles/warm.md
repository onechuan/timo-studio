# 温暖插画的画面语言

温暖纸色背景，深棕文字，陶土色强调主体、鼠尾草绿辅助。把同一对象跨页画成同一种形态，颜色含义保持一致。一页用一个明确主体承担主要信息，主体特写可占画面一半；不要把汤碗、树、杯子缩成一个小图标，再用大片文字填满。

构图先决定观众第一眼看哪里。主体特写适合物品、现象与问题；左右对照让条件或结果改变；过程演示把真实物件按动作连接；时间推进展示同一主体的变化；系统关系只用于确实存在的结构。多页内容应自然变化构图，不要每页都做三个卡片、中央节点或标题加列表。

用有体积的扁平矢量物件、少量清楚的轮廓线、有限的内部细节。大块形状建立识别，细节说明主题：汤里的食材、杯外的水滴、清单中的选中项。优先图形表达，再加少量短标签。字体深色，强调色只突出一处，不使用荧光、玻璃、渐变堆叠和装饰光晕。

从第一句开始就有主体；解释到条件、步骤或结果时，再出现对应对象、连线或说明。一次变化讲清一个关系，出现后停住给人阅读。标题不重复字幕，画面文字不抄整段口播。图像是讲解示意，不能冒充历史图像、真实产品截图或科学测量。
