# TimoTV 品牌手绘信息图

炭黑底 paper=#111514，米白 ink=#f2efdf，浅绿 accent=#c8ee8a，灰绿 muted=#929e96。只用一处浅绿强调当前结论，主轮廓用米白，关系线用灰绿。背景由渲染器绘制，不再用大矩形或椭圆铺底。右上角 TimoTV 由渲染器固定绘制，禁止重复生成 Logo；片头可将 TimoTV 作为中央主标题。

先确定一条视觉隐喻，再决定图元。画面应该是有主体的编辑插图：例如折叠纸张代表现成答案，拆开的结构代表基本事实，原材料层与电池轮廓代表成本构成。不能将一切都画成方框、箭头与长句。

手绘感来自连续的轻微弯曲线条和不完全对称轮廓，不靠抖动、随机粒子或堆叠椭圆。以细线轮廓为主，path 使用 fill=none、stroke=ink/accent、strokeWidth=2..4。小面积强调可填 accent，禁止大面积刺眼色板与厚重蒙版。主体不超过三个视觉簇，正文标签通常2–4个，每个2–6字，字号32..40；文字有独立留白，不能跨过轮廓或放在色彩相近的物体上。

横版主体集中在 x=180..1420,y=220..650，留出标题和字幕。对照页左右对称，中间至少120像素间距；机制页使用连续线明确连接因果；片头有大量留白、醒目品牌字和一个明确的播放画面隐喻。不复制系统标题。优先使用一个完整 path 描述一个轮廓，子部件用 group，主体身份跨句保持。

每页一个主动作：拆开、合并、上推或强调。按真实口播渐进出现，控制运动幅度，结束后让观众看清关系。初态、中途、末态都要检查文字遮挡，不能把最终效果的美观建立在前半段混乱之上。
