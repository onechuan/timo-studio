# 科技图解的画面语言

深石墨背景，浅色主文字，青绿色强调运行中的对象，蓝灰色辅助。布局精确，少用装饰；不用霓虹光圈、玻璃卡片堆叠或无意义粒子。

技术结构应画出输入、处理、工具、结果之间的实际关系。Agent 主题可用明确的任务文档、推理主体、工具箱、终端和反馈路径；每条箭头表达具体的数据流或控制流，不把术语随意围成一圈。数据、步骤和实体分层排列，一页最多一个主要流向，环路只在解释反馈时出现。

系统关系不是所有页面的默认构图。解释单个部件用大主体，比较方式用左右对照，执行过程用序列，演进用时间推进。图像占据主要区域，少量标签放在图旁，长句交给口播与字幕。生成的界面只作原理示意，不虚构产品能力。

真实口播先介绍输入，再出现处理和输出；后续反馈在对应句出现。保持对象位置稳定，变化建立在前一步上。配色语义跨页一致，首帧有内容，页末停稳。
