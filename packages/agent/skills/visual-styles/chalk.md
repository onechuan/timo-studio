# 黑板讲解的画面语言

深绿黑板底，暖白文字与主轮廓，粉笔黄强调当前概念，浅绿表示辅助关系。用清楚的大轮廓、简洁剖面和少量手绘感图形表达机制；不能把所有场景都做成思维导图。

一个板面只解释一件事：现象用主体特写，机制用方向明确的过程，对比用等宽两侧，时间用有顺序的演进。对象要大，连接要有因果含义，文字不能铺满黑板。深色背景上的文字用 ink，辅助标签用 muted，核心变化用 accent。禁止低对比深色字。

首句先有完整主体轮廓，随着真实口播逐步加入条件、指向和结果；draw 用于线条、箭头，fade 或 rise 用于对象和说明。不要随机抖动、循环闪烁或让所有信息同时出现。字幕区域留空。
