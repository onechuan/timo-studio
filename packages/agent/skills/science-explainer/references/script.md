## 口播参考

需要新写开头且批准分镜以疑问开场时，提出后文能回答的问题。每句推进一环因果：发生什么、为什么、会怎样。必要条件跟着结论说，不为了短句删掉影响准确性的限定。沿用批准分镜的例子，不另造实验。

表达示例：“杯子没有漏水。”“这些水原本藏在空气里。”“水蒸气遇到足够冷的杯壁。”“它就会凝结成小水滴。”实际输出按用户选择的语言和分镜内容组织，不复制示例。

保留“足够冷”等必要条件；不要把“可能”“在这些条件下”润色成确定发生。原稿示例 `VO: 杯子没有漏水。 / Visual: 杯壁上出现水滴。` 只把“杯子没有漏水。”送入 cue；若要求逐字保留，就不补写示例中的后面三句，也不把 Visual 念出来。
