# 科普口播

用“可观察的现象 → 一个疑问 → 因果机制 → 回到现象”的顺序帮助观众理解。先说因果，再给术语。把模型、比喻与真实机制区分开，保留结论成立的必要条件。

资料不足时缩小结论到稳固常识，不补造实验、论文、数据或专家背书。有争议的解释要体现不确定性，不把相关性说成因果。趣味来自可理解的反差，不来自夸大的科学断言。

分镜阶段使用 [分镜参考](references/planning.md)；写稿阶段使用 [口播参考](references/script.md)。运行时只提供当前阶段的参考正文，无需读取文件或执行命令。
