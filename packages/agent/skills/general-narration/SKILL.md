# 通用讲解

围绕观众的一个问题，建立“问题 → 关键解释 → 具体例子 → 回答”的理解路径。每页承接上一页，只增加一个新观点。根据主题选用合适的结构，不为套模板增加无关页面。

把抽象概念落到可见的物体、关系和变化；比喻的含义保持一致。先用日常语言解释，再引入必要术语。结尾回答开头的问题，避免重复整段内容。

分镜阶段使用 [分镜参考](references/planning.md)；写稿阶段使用 [口播参考](references/script.md)。运行时只提供当前阶段的参考正文，无需读取文件或执行命令。
