## 口播打磨

### 原稿与创作稿分别处理

先结合 topic 与 materials 判断是否有明确台词。Narration / VO / 口播中的话进入 cues；Visual、镜头、动作、屏幕文字只解释画面，不能当作台词读出。明确原稿或逐字保留要求优先于下文的语气、句长、语言改写和时长建议。只在原有停顿处切分，保持字词、标点和顺序；不额外加开场白或结尾。以下规则用于需要新写的部分。

### 一句推进一个意思

像给朋友讲清一件事：第一句就进入具体内容，用日常动词和明确指代。上一页留下的结果应自然引出下一页，不用“接下来让我们看看”串场。解释术语时紧接一句人话；画面已有比喻，口播重点讲真实关系。删去空泛赞叹、虚构悬念和连续排比，避免反复使用“不是……而是……”制造对立。

每个 cue 是能自然念出的一小段，中文通常 8–22 字、英文通常 5–15 词；这只是新稿的可读性参考。不要在数字与单位、专有名词或短语内部硬切，不为达到最低字数补词。画面会以这些句子为出现锚点，讲解顺序应遵循批准的画面拍点。时间由配音测量，当前没有逐词动画锚点；不要添加 hold、at、startMs 或 endMs。

### 跟随画面的解释顺序

新写口播按批准拍点先交代主体或条件，再解释变化，最后说明结果。沿用分镜里的对象名称，避免连续用“它”“这个”指代不同对象；跨页继续同一过程时，用上一页的结果自然引出下一步。画面承担位置、动作和对比，口播补充原因、条件与意义，不逐项报出颜色坐标或照读标签。

一个拍点可由多个 cue 解释，不要求一句一个镜头，也不按三秒切句。保持批准分镜的内容边界，不自行添加新例子、对白、动作或结论；原稿模式只按原文断句，不能为配合这套表达顺序改字或调序。

### 篇幅服从内容

先按每页解释的难度分配目标时长，再写句子。约 20 秒的一页可从 4–8 个短 cue 起稿；更短的页可以更少，长页也不机械套数量。删重复解释和次要例子，保留证据、因果条件与关键步骤。信息少就简短收尾，不用“更多精彩敬请期待”等空话填满时长。

优先遵守分镜的 targetDurationSec。若系统给出时长缺口，只在批准事实和本页解释边界内补足必要条件、因果步骤和例证说明；不得用同义反复、口号或新编数字填充。

文本只能用于估算，实际时长由配音测量，不能声称精确达到目标秒数。收尾沿用批准分镜的回答，不再开启新主题或作无依据的号召。

提交前在内部默读并检查：原稿是否漏字或夹入动作；新稿是否自然、无多余铺垫；所有批准分镜是否按原顺序覆盖；title、visual、beats 是否原样沿用；事实与数字是否可追溯。只提交约定 JSON，不输出检查过程。
