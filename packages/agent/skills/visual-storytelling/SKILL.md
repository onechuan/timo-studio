# 绘图与动画叙事

本 Skill 只用于配音后的逐页绘图与修复。基础 Prompt 定义输出协议、图形能力和安全区；这里说明如何让画面解释批准内容。只通过 submit 提交完整页面，不增加脚本、素材提取或视频生成工具调用。

## 从拍点到画面

先读 visual、beats、layout 与 cues，确定本页一个核心关系。在内部将拍点对应到真实句子：初态让观众认出主体，变化阶段突出一个主动作，末态留下可观察结果。用少量对象把关系画清，不为每个名词建立一个图形，不用整句文字替代主体。

每页一个明显视觉中心。主体尺寸足够辨认，标签只解释具体对象或关系，通常 2–4 个短标签即可；次要对象服从阅读顺序。接触、容纳、连接与方向关系必须可读，例如液体留在容器内部，水滴出现在杯外。背景放低层，组合部件以 parentId 和 layer 表达有意叠放；标签放在主体外的留白。

## 让同一个对象经历变化

页内同一对象沿用 ID，通过轨道改变位置、颜色、状态或形状，不重复创建多个主体伪装连续动作。稳定对象保持位置，只有承担解释作用的对象运动；静态对照用显隐或强调轨道展示差异，不为热闹旋转整页。

| 讲解变化 | 可执行表达 |
| --- | --- |
| 从一处移动到另一处 | move；组合实体移动其 group，避免部件散开 |
| 液位上升、节点激活、信息传递 | 对应 component 的 parameter 或 state |
| 逐步强调差异 | color / opacity，结束时保留需要比较的对象 |
| 轮廓连续改变 | 同拓扑 path；不同拓扑使用两个明确状态交叉淡化 |

完整 illustration 是不可拆分的成品。外观适配时优先复用；要改变内部液位、结构或特定服饰时，按基础 Prompt 选择可控组件或完整自绘对象，不能给成品插画叠第二套内部结构。

previousArtwork 仅用于参考上一页实际形态和结果，不是自动共享的对象库。连续演示同一过程时，从上一页对应轨道的末值识别位置、液位、颜色或状态，在本页显式重建初态，并沿用关键轮廓、配色和相对位置。需要重构图时维持对象身份，不能把新构图误画成无解释的状态重置。每页依然完整定义自己的 elements 和 tracks，ID 引用只限本页。

## 动作跟随真实口播

以输入 cueId 和句内 progress 锚定动作，不生成独立的三秒时间表。先让主体可见，再在对应讲解句中发生变化，动作结束后留出可读的末态。若同句承载多个小变化，按句内先后安排，不让所有对象同时抢占注意力。

轨道首个关键帧的值会用于之前的时间：希望中途开始运动，就在对应 cue 的起点写出初始值，再写结束值。需要延迟出现的对象使用正确的 cueIndex 或显隐轨道，避免结果提前泄露。使用真实 cueId，时间严格递增，不通过修改口播或编造句长给动画腾时间。

例如冷杯凝结：首句显示完整冷杯；讲到杯外空气时，让少量示意粒子靠近杯壁；讲到凝结时，粒子淡出、杯外水滴显现；末态保留杯壁与水滴。粒子与水滴是明确的两个状态，无需强行进行不同拓扑形变。示意不暗示杯内液体穿过杯壁，不使用带蒸汽的热杯成品充当冷杯。

## 提交与修复

内部检查初态、动作中途和末态：主体能否认出，当前口播所说的变化是否可见，运动路径是否侵入标题字幕区，缩放或旋转后是否越界，标签是否被挡。静态自查不代表已经通过截图或视觉模型审片。

收到 originalArtwork + feedback 或 repair.draft + issues 时，以提供的候选为基础，定位问题对象及相关轨道，保留未受影响的主体身份、构图和有效动画。移动标签时只调整标签及必要的关联指示线；若问题来自运动途中，修正对应关键帧或父组关系，而非只改静态坐标。修复后重新检查关联对象，返回完整页面。不能用大蒙版遮住问题，也不能通过删除关键讲解内容、修改口播或改动其他页规避反馈。
